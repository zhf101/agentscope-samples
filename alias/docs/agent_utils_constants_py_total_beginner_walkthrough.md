这个文件存放 agent 运行期常量和默认文案。

## 主要内容

1. 重试/迭代上限
- `MODEL_MAX_RETRIES`
- `PLANNER_MAX_ITER`
- `WORKER_MAX_ITER`

2. 默认命名
- `DEFAULT_PLANNER_NAME`
- `DEFAULT_BROWSER_WORKER_NAME`

3. 模式描述文案
- 浏览器/深研/数据科学等描述字符串

4. 临时目录
- `TMP_FILE_DIR`
