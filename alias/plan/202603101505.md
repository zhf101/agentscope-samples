# cdp 重构精简计划 (基于 alias)

日期: 2026-03-10

**目标**
将 alias 精简为 cdp 项目，仅保留:
1. 构建分解问题与规划路径能力 (Meta Planner)
2. 通用 general 模式
3. 浏览器 browser-use 模式
4. OpenAI 兼容格式的自部署模型调用

**移除范围**
1. 深度研究 deepresearch 模式
2. 金融分析 finance 模式
3. 数据科学 ds 模式
4. DashScope/ModelScope 相关模型与多模态能力
5. ModelScope 的图像/视频理解与音频转写相关工具

**范围内保留/调整**
1. 规划与任务分解流程继续保留 (MetaPlanner + WorkerManager)
2. Browser Agent 保留网页交互能力
3. LLM 仅保留 OpenAIChatModel/Formatter 兼容层
4. 文档、CLI、API 模式枚举同步精简

**文件级改动清单 (高优先级)**
1. CLI 模式与路由精简: `src/alias/cli.py`
